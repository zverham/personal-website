Update the Now page (`now.qmd`) with what the user is currently reading, listening to, playing, and watching.

## Instructions

Read the current contents of `now.qmd` so you can show the user what's there.

Then ask the user for each of the four sections:
1. **Reading** — books (title + author)
2. **Listening** — music or podcasts
3. **Playing** — games
4. **Watching** — shows or films

For each section, ask what they want to add, remove, or replace. They can say "same" or "no change" to leave a section as-is. They can also say "clear" to wipe a section clean.

Once you have all updates, rewrite the body of `now.qmd` with the new content. Keep the frontmatter and the italic note at the top unchanged. Format each section as a bullet list.

After updating, tell the user the file has been saved and remind them to commit and push to publish.
